# Security Policy

## Supported version

This repository publishes a static personal website. Security fixes are applied to the current `main` branch and the live GitHub Pages deployment.

## Reporting a vulnerability

Please do not publish exploit details, credentials, tokens, or personal information in a public issue.

Use GitHub's private vulnerability reporting flow for this repository:

<https://github.com/StarsofDeduce/StarsofDeduce.github.io/security/advisories/new>

Include the affected page or file, reproduction steps, expected impact, and any suggested remediation. Reports will be reviewed before public disclosure.
