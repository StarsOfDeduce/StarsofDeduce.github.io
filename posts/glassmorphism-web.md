## ✨ 为什么现在的极客主页都在用 Bento Grid？

Bento Grid（便当盒栅格）源于日本便当盒将食物分门别类、整洁排列的理念。在当今数字化设计中，Apple、Linear、Vercel 等顶级科技公司纷纷将其发扬光大：

1. **高密度信息呈现**：在一屏之内清晰囊括作品、指标、动态与社交；
2. **节奏明快**：打破传统的单列通栏式文章列表，页面更有现代节奏感；
3. **沉浸式微交互**：卡片悬浮、跟随光晕、动态指标，让访客在浏览时感到生动有趣。

---

## 🎨 毛玻璃拟物（Glassmorphism）的 CSS 秘诀

在打造属于自己的个人主页时，纯粹的扁平化早已让人审美疲劳。通过适度引入毛玻璃与高光，可以让卡片呈现出类似悬浮玻璃板的高级质感：

```css
.card {
  background: rgba(255, 255, 255, 0.05);
  backdrop-filter: blur(20px);
  -webkit-backdrop-filter: blur(20px);
  border: 1px solid rgba(255, 255, 255, 0.08);
  border-radius: 18px;
  box-shadow: 0 8px 32px rgba(0, 0, 0, 0.25);
}
```
